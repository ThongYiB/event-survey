# ลงทะเบียนและ QR — ขั้นที่ 2

ติดตั้งตาราง `event_publications` และ `registrations` ในโปรเจกต์ Supabase จริงแล้วเมื่อ 19 พฤศจิกายน 2026 ใช้ migration `202611190002_registration.sql`

## วิธีใช้งาน

1. เข้าสู่ระบบ Event Manager สร้างหรือเลือกอีเวนต์
2. บันทึกรายละเอียดงานและฟอร์มลงทะเบียน ต้องมีช่องชื่อและอีเมลแบบบังคับ
3. เปิด QR Center กำหนดเปิดรับและจำนวนที่รับ (0 คือไม่จำกัด) แล้วกดเผยแพร่การตั้งค่า
4. ส่งลิงก์หรือดาวน์โหลด QR ของอีเวนต์นั้น ผู้เข้าร่วมกรอกข้อมูล ตรวจสอบ แล้วกดยืนยัน
5. ตั๋วส่วนบุคคลเปิดซ้ำได้จากเบราว์เซอร์เดิม 30 วัน และดาวน์โหลด QR เป็นรูปภาพได้
6. Manager เปิดผู้ลงทะเบียนเพื่อดูรายชื่อ ค้นหา แบ่งหน้า และดูข้อมูลที่กรอกจริง

เมื่อแก้รายละเอียดหรือฟอร์ม ต้องเผยแพร่ใหม่เพื่ออัปเดตหน้าสาธารณะ การปิดรับไม่ลบตั๋วเดิม

## ข้อมูลและสิทธิ์

- บุคคลทั่วไปอ่านได้เฉพาะรายละเอียดและฟอร์มที่เผยแพร่ผ่าน API ของแอป ไม่สามารถอ่านตารางรายชื่อโดยตรง
- Manager อ่านได้เฉพาะรายชื่อในงานของตนเอง ไม่มีสิทธิ์อ่าน ticket code หรือ request key จากตาราง
- ตั๋วใช้รหัสสุ่ม 128 บิต เก็บสิทธิ์เรียกดูไว้ในคุกกี้ HttpOnly, SameSite=Lax และ Secure บนเว็บจริง ไม่ใส่รหัสตั๋วใน URL
- QR ใช้รูปแบบ `ES1:<event UUID>:<ticket code>` สำหรับต่อระบบสแกนในขั้นถัดไป
- อีเมลลงทะเบียนได้ครั้งเดียวต่ออีเวนต์ การส่งซ้ำด้วย request key เดิมคืนตั๋วเดิม
- ฐานข้อมูลล็อกแถวอีเวนต์ระหว่างลงทะเบียน ป้องกันจำนวนเกินเมื่อหลายเครื่องส่งพร้อมกัน
- เก็บ snapshot ชื่อช่องของฟอร์มกับคำตอบ เพื่อให้รายชื่อเดิมอ่านได้หลังแก้ฟอร์ม
- หากล้างคุกกี้หรือเปลี่ยนเครื่อง ใช้รูป QR ที่บันทึกไว้ การกู้ตั๋วผ่านอีเมลยังไม่อยู่ในขั้นนี้

## การตรวจสอบ

- `node scripts/test-registration-policies.mjs` ทดสอบ PostgreSQL แยกในเครื่อง: สิทธิ์เจ้าของ การแยกข้อมูล ความเป็นส่วนตัวตั๋ว จำนวนที่รับ อีเมลซ้ำ การส่งซ้ำ ฉบับฟอร์ม และการปิด/ระงับงาน
- `node --env-file=.env.local scripts/test-registration-live.mjs` สร้างบัญชีและงานที่ระบุ `[QA registration]` แยกชัดเจน เพื่อทดสอบ API กับฐานข้อมูลจริง แล้วเตรียม fixture ใน `.vercel/registration-qa.json` ซึ่ง Git และ Vercel ไม่อัปโหลด
- หลังตรวจหน้าจอ ใช้ `node --env-file=.env.local scripts/test-registration-live.mjs --cleanup` ลบเฉพาะบัญชี งาน และรายชื่อ QA ที่สคริปต์สร้าง

การรับคำตอบแบบสอบถาม การสมัคร Staff ผ่าน QR การสแกนเช็กอิน Walk-in และรายงานรวมยังเป็นงานขั้นถัดไป

## ผลทดสอบก่อนส่งงาน

ตรวจผ่านทั้งในเครื่องและบน https://event-survey-one.vercel.app: ล็อกอิน Manager เผยแพร่ฟอร์ม ลงทะเบียนใหม่ ส่งซ้ำ ตรวจจำนวนที่รับ เปิดตั๋วจากคุกกี้ ปิดรับ และอ่านรายชื่อด้วยสิทธิ์ Manager รวมถึงทดสอบสมัครจากหน้าจอและรีเฟรชตั๋วจริงด้วย ข้อมูลและบัญชี QA ถูกลบหลังตรวจเสร็จ ไม่ใช้รายชื่อผู้เข้าร่วมจริงในการทดสอบ
